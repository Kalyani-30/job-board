# Jobs (Frontend-only React + Vite + Tailwind)

LinkedIn/Naukri-style job board UI with:
- Search and filters (location/type/experience)
- Job details page
- Frontend-only “Apply” simulation (no login, no backend)

## Run

```bash
cd Jobs
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Data

- `jobs.json` is served from the frontend (static file) and contains the sample jobs dataset.
